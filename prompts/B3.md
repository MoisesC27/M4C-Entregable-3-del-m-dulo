# B3 — Registro de uso de inteligencia artificial

## Herramientas utilizadas

Durante el desarrollo del Entregable 3 se utilizó ChatGPT como asistente para revisar la aplicación AIRLINCOLN, interpretar errores, documentar mejoras y preparar verificaciones.

## Actividades realizadas

### 1. Accesibilidad y contraste WCAG

Se solicitó orientación para implementar una verificación automática de contraste de colores conforme a los criterios WCAG 2.2 AA.

Se trabajó con `ui/theme.py`, `scripts/verificar_contraste.py` y `.github/workflows/contraste.yml`.

**Resultado:** se corrigieron las combinaciones de colores verificadas y se obtuvo una ejecución exitosa en GitHub Actions.

### 2. Estado vacío

Se revisó el uso de `st.stop()` en `app.py` para evitar el procesamiento del dashboard cuando no existen datos cargados.

**Resultado:** se propuso agregar un mensaje informativo y detener la ejecución en la pantalla de selección de archivos. 
**Resultado:** Se agregó un mensaje informativo en `app.py` y se utilizó `st.stop()` para detener la ejecución cuando el usuario todavía no selecciona un archivo. Se comprobó que la aplicación muestra el aviso sin ejecutar el dashboard y que permite continuar al cargar el archivo de ejemplo. También se probó el rechazo de archivos que no cumplen las condiciones necesarias para el análisis.


### 3. Controles de negocio

Se analizaron los controles del simulador de sobreventa y del calendario de vuelos de Laura.

**Resultado:** se verificó mediante capturas que distintos escenarios producen recomendaciones diferentes y que el calendario permite seleccionar fechas y vuelos.

### 4. Autenticación y roles

Se revisó el inicio de sesión de Laura, Armando y Anna, así como la diferenciación de sus dashboards.

**Resultado:** se documentó una matriz de acceso por roles y se identificó la necesidad de verificar las restricciones de autorización de las operaciones sensibles.

### 5. Documentación

Se utilizó el asistente para estructurar `docs/entregable-3.md`, incluyendo preguntas de negocio, contraste, jerarquía visual, estado vacío, controles y autenticación.
